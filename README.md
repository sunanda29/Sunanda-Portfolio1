# Sunanda Portfolio
A discreet interactive professional portfolio built with React and Vite.

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Before publishing
Replace `YOUR_EMAIL@example.com` in `src/components/Contact.jsx`.

## Deploy
Push this project to GitHub, then import the repository into Vercel. Vercel should detect Vite automatically.
